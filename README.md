A modern, responsive, and high-performance personal developer portfolio built with **React 19**, **Vite**, **Tailwind CSS 4**, and **React Router 7**. Designed with rich aesthetics, smooth micro-interactions, dynamic statistics, and dedicated deep-dive project showcase pages.

---

## 🌟 Highlights & Key Features

- **⚡ Blazing Fast Performance:** Powered by Vite 7 with instant HMR and optimized production bundles.
- **🎨 Modern Design & Glassmorphism:** Clean UI with subtle gradients, responsive typography, soft shadows, and clean pill navigation.
- **📱 Fully Responsive:** Adaptive layouts optimized across mobile phones, tablets, laptops, and ultra-wide desktop viewports.
- **📂 Categorized Project Showcase:** Interactive category filtering (**Fullstack**, **Mobile**, **Game**, **Frontend**) with zero overlapping clutter.
- **🔍 Dedicated Project Detail Pages:** Deep-dive case studies for each project including architectural highlights, feature lists, tech stack badges, and GitHub links.
- **📊 Dynamic Portfolio Metrics:** Auto-calculated stats computing total projects, years building, technologies mastered, and responsive coverage.
- **📄 Instant CV / Resume Download:** Seamless cross-browser resume download directly from the navigation bar, hero section, and about cards.
- **📬 Interactive Contact Hub:** Direct email, LinkedIn, and GitHub links for quick recruitment and collaboration outreach.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18+ or later) installed.

### 1. Clone the repository
```bash
git clone https://github.com/ImashaSamodee/Imasha-Samodee-Portfolio.git
cd Imasha-Samodee-Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for production
```bash
npm run build
```
